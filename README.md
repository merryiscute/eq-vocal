# EQ Vocal Coach

파라메트릭 EQ와 음성과학 지표로 발성을 진단하고, **EQ로 목표 소리를 먼저 들어 본 뒤 연습으로 그 소리를 만드는** 브라우저 앱.

## 왜 이 구조인가

EQ는 녹음된 소리를 바꿀 뿐 성대를 바꾸지 못한다. 그래서 EQ를 두 가지 용도로만 쓴다.

| 역할 | 하는 일 |
|---|---|
| 진단 렌즈 | 내 목소리의 평균 스펙트럼(LTAS)에서 대역별 문제를 수치로 찾는다 |
| 청각 목표 | "울림이 생기면 이런 소리"를 EQ로 미리 들려줘 귀를 먼저 훈련시킨다 |
| EQ 역진단 | 내가 듣기 좋게 만진 EQ(또는 DAW 프리셋)를 거꾸로 읽어 발성의 부족·과잉을 진단한다 |
| (실제 개선) | 진단 결과마다 연결된 **발성 연습**이 담당한다 |

## 쓰는 법

```bash
npm start
```

브라우저에서 `http://localhost:8080` 을 연다. 마이크는 보안 컨텍스트(localhost 또는 HTTPS)에서만 열린다.

1. "아—"를 편한 음으로 곧게 5초 녹음 (또는 오디오 파일 업로드)
2. (선택) 코를 막고 같은 음으로 한 번 더 → 콧소리 확인
3. 진단 카드 → 연습법 확인 → "제안 EQ 적용"으로 목표 음색 A/B 듣기
4. 원하는 소리가 될 때까지 EQ를 만지거나 DAW 보컬 EQ를 붙여 넣는다 → **EQ 진단**
5. 매일 같은 조건으로 재서 **첫 기록 대비 변화**를 본다

## EQ 진단 (EQ → 발성)

원리는 **올린 대역은 원래 부족한 것, 깎은 대역은 원래 과한 것**이다. EQ 응답을 7개 보컬 대역별 평균 게인으로 바꾼 뒤 `src/eqdiag.js`의 `ZONES` 표에 따라 판정한다.

| 대역 | 올렸다면 | 깎았다면 |
|---|---|---|
| 초저역 20–90 Hz | 취향 (발성 무관) | 일반적인 믹스 정리 (발성 무관) |
| 몸통 90–250 Hz | 소리가 얇음 | 저역 붕붕거림 → 마이크 근접 효과부터 의심 |
| 먹먹함 250–600 Hz | 가볍고 납작함 | 먹먹하고 막힘 |
| 콧소리 0.7–1.5 kHz | 소리가 뒤로 숨음 | 콧소리 → 코 막기 녹음으로 확인 |
| 울림 2–4 kHz | **울림 부족** (가수 포먼트, Sundberg 1974) | 날카롭고 쏘는 소리 |
| 치찰음 5–9 kHz | 발음이 뭉개짐 | ㅅ·ㅆ 과다 |
| 공기감 10–16 kHz | 취향 | 숨소리 또는 잡음 → HNR로 구분 |

판정을 오염시키지 않도록 넣은 규칙:

- **볼륨 무시**: 100 Hz–8 kHz 응답의 중앙값을 빼서, 전체를 올린 것은 음색 변화로 보지 않는다.
- **번짐 처리**: 셸프나 넓은 벨이 옆 대역까지 움직이면, 더 크게 움직인 대역 하나로만 판정한다.
- **원인 분류**: 원인을 발성 · 마이크·환경 · 발음 · 취향으로 나누고, 발성이 아닌 원인은 "참고"보다 높게 판정하지 않는다.
- **환경 경고**: 한 대역을 10 dB 이상 바꾸면 "발성보다 녹음 환경부터 확인"을 띄운다. 하이패스는 예외.
- **귀와 측정 교차 확인**: 녹음이 있으면 EQ로 고친 것과 측정값(SPR, Alpha ratio, HNR, 코 막기 차이)을 비교해 일치/불일치를 표시한다. 불일치라면 원인이 발성이 아니라 이어폰·스피커·방일 수 있다는 신호다.

DAW 프리셋은 한 줄에 밴드 하나다. 종류(HPF/LPF/LS/HS/Bell) · 주파수 · 게인 · Q 순서이고 `HPF 80Hz`, `300Hz -3dB Q1`, `3k +4 1.4`, `HS 10k +2` 같은 표기를 받는다. 잘못된 줄은 줄 번호와 이유를 알려 주고 건너뛴다. 소수점 쉼표(`1,5`)는 지원하지 않는다.

## 측정 지표

| 지표 | 계산 | 근거 | 기준값 |
|---|---|---|---|
| F0, 음정 흔들림(cent SD) | 창 보정 자기상관 | Boersma (1993) | 20 / 40 cent — **임시** |
| HNR | 자기상관 피크 r → 10·log10(r/(1−r)) | Boersma (1993), Praat 매뉴얼 | 20 / 13 dB — Praat의 "건강한 [a] ≈ 20 dB" 참고, **임시** |
| SPR | LTAS 2–4 kHz 최대 피크 − 0–2 kHz 최대 피크 | Omori et al. (1996) | −20 / −28 dB — **임시** |
| Alpha ratio | 1–5 kHz 에너지 / 50 Hz–1 kHz 에너지 | Frøkjær-Jensen & Prytz (1976) | −25 / −5 dB — **임시**, 참고용 |
| 콧소리 | 정상·코 막은 녹음의 1/3옥타브 스펙트럼 모양 차이 | 코 막기 비교(경험칙) | 1.5 / 3 dB — **미검증** |

모든 임계값은 `src/rules.js`의 `THRESHOLDS` 한 곳에 모여 있다. **기준값은 임상 규준이 아니다.** 마이크·방·거리에 따라 절대값이 달라지므로 앱은 남과의 비교 대신 본인 기록 추이를 보여 준다.

## 검증

```bash
npm test
```

합성 신호(배음 + 시드 고정 잡음)로 검증한다 (31개 테스트):

- F0: 98–784 Hz에서 오차 1% 이내, 옥타브 오류 없음
- HNR: 실제 배음/잡음 전력비 이론값과 **1 dB 이내** (이론 19.5 dB → 측정 19.4 dB)
- SPR·Alpha ratio: 2–4 kHz 배음을 키우면 상승
- 같은 입력 → 같은 결과 (결정론)
- EQ 응답: RBJ Cookbook 공식, 피킹 중심 게인 정확, 셸프 코너 −3 dB
- EQ 진단: 평탄 → 진단 없음, 3 kHz +5 → 울림 부족, 80 Hz HPF → 발성 문제 아님, 전체 볼륨 증가 → 진단 없음, 셸프 번짐 → 한 대역만, 프리셋 파서 표기·오류 처리

브라우저 종단 검증(Chromium, 가짜 마이크로 합성 WAV 입력)에서 마이크 녹음 경로와 파일 업로드 경로의 결과가 일치했다 (HNR 17.1 vs 17.3 dB, 흔들림 22.5 vs 22.4 cent).

## 한계

- **실제 사람 목소리로는 아직 검증하지 않았다.** 합성 신호 검증만 끝난 상태.
- 비브라토는 음정 흔들림 수치를 올린다 — 측정할 땐 곧게 낸다.
- 지속 모음 "아" 전용. 노래 가사·자음이 섞이면 수치가 불안정하다(유성 프레임 50% 미만이면 재녹음 요청).
- 콧소리 판정 기준과 연습법 다수는 경험칙이며 앱에 그렇게 표시된다.
- EQ 진단의 대역 ↔ 발성 대응은 울림(2–4 kHz)만 연구 근거가 있고, 나머지는 보컬 믹싱·발성 교육의 경험칙이다. EQ는 "듣는 기기"의 영향도 받는다. 이어폰이 어두우면 고역을 올리게 된다. 그래서 녹음 측정과 교차 확인하는 기능을 넣었다.
- 서지 정보는 작성자가 기억에 의존해 기입했다. 인용 전 원문 확인 필요.
- 진단 기기가 아니다. 쉰 목소리가 4주 이상 지속되면 이비인후과 진료 (AAO-HNS 2018 가이드라인).

## 구조

```
index.html, styles.css    UI (빌드 단계 없음, 의존성 없음)
src/analysis.js           순수 분석: LTAS, F0, HNR, SPR, Alpha ratio
src/rules.js              결정론적 진단 규칙 + THRESHOLDS
src/eqdiag.js             EQ → 발성 역진단 (ZONES 표) + DAW 프리셋 파서
src/knowledge.js          연습법·근거 문헌 (연구 근거 / 경험칙 구분)
src/eq.js                 RBJ 바이쿼드 수학 + Web Audio 체인
src/audio.js              원시 PCM 녹음(AudioWorklet), 파일 디코딩, 재생
src/main.js               화면 연결
test/                     node --test 단위 테스트
```

녹음 시 브라우저의 자동 게인·잡음 제거·에코 제거를 끈다. 이 처리들이 스펙트럼을 바꿔 모든 수치를 오염시키기 때문이다. 압축 코덱도 거치지 않도록 AudioWorklet으로 원시 PCM을 받는다.
